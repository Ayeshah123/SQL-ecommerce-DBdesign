# E-commerce SQL Database Project

## Overview
This project is a relational database for an e-commerce system built using SQL Server.

## Features
- Customers management
- Product catalog
- Orders system
- Order details with product mapping
- Foreign key relationships

## Tables
- Customers
- Products
- Categories
- Suppliers
- Orders
- OrderDetails

## Skills Used
- SQL Server
- Database design
- Primary & Foreign keys
